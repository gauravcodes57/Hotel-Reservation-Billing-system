# Project Statement

## Problem Statement

Manual hotel reservation and billing processes can require separate handling of room availability, guest details, additional services and bill calculation. A simple computerized system can combine these activities into one logical workflow.

## Scope

The project focuses on a basic hotel reservation and billing process through a command-line Python application. It manages room information, guest details, hotel services, billing and payment selection.

The project does not use a database or online payment system.

## Target Users

The system is intended for a basic hotel reservation workflow and can be used as a simple demonstration of hotel booking and billing operations.

## High-Level Features

1. Room availability and selection
2. Guest and booking management
3. Hotel service selection
4. Bill calculation with GST
5. Payment method selection
6. Booking confirmation or cancellation
